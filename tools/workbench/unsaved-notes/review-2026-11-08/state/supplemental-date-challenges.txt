S3. Begin a delayed valid import, enter native partial date while waiting, and resolve read. Existing notes and partial date must survive rejection by revision/race protection. If replacing current partial-date-only state with no other notes, ask for replacement confirmation rather than silently discard it.
S4. Open preview, restore note/select/date controls without input/change, dispatch pageshow. Preview and select helper must agree with restored controls, dirty state true; restoring checkpoint values clears changed state and refreshes preview. This extends original frozen pageshow case and is supplemental, not a holdout.
S5. A pending read with no date edits should not falsely fail just because the unchanged date control receives blur/keyup.
