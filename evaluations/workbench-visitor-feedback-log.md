## Evidence rules

- Record a real visitor comment only when it has actually been received. Link to the public discussion when appropriate; do not invent private feedback.
- Mark comments as user reports, not independently verified defect descriptions. Reproduce defects where possible and keep negative findings.
- Distinguish software/fictional tests, unsolicited visitor feedback and controlled independent comprehension research.
- Avoid reporting adoption rates or satisfaction percentages from comments or page views. Do not assume silence means success.
- If there is no feedback, say so. Continue automated and adversarial testing without claiming it substitutes for user understanding.
