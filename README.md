# Practical AI Adoption

Plain-English, evidence-grounded guides for using AI well at work. No technical background required.

This repository starts with one practical habit: give AI a better brief, then check what comes back. The examples are fictional. The tests say exactly what they do and do not show.

## Start here

[Prompting Fundamentals: Give AI a Better Brief](guides/prompting-fundamentals.md) gives you a short prompt starter you can copy, paste into the AI tool you already use and adapt to a real task.

## See it tested

[Thornfield Team Connect: Prompting Example](examples/thornfield-team-connect-prompting-example.md) compares an ordinary first attempt with a guide-informed prompt using the same fictional evidence.

## Read the honest review

[Thornfield Team Connect: Prompting Review](evaluations/thornfield-team-connect-prompting-review.md) scored the baseline at **24/30** and the guide-informed result at **30/30**. Neither output automatically failed. This is fictional testing only.
