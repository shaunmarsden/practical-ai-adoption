Privacy and how this works

Answers stay in this page's memory. There is no account, analytics, AI API or server storage of answers. Refreshing or closing the page clears them, though your browser may retain form values through its own session recovery. No browser storage is used by this application. JSON and PDF exports are files saved to your device; handle and delete them under your organisation's rules. Import reads a file locally. GitHub Pages receives normal page and asset requests, never your submitted answers. All scripts and the PDF font are served with this site.
