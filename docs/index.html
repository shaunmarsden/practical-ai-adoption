Use the Starter on Your Own Notes

The rewritten prompt is in the guide, ready to copy. Bring notes you are allowed to put in the tool your organisation has approved.

Nothing on this page is a live AI call. A static page cannot reach a model without a backend. The sorting you are marked against, and the three mistakes shown at the end, come from a run that was recorded and scored in this repository before this page existed.

The honest part of the result. Rewriting that prompt fixed the defect it was written for: all three misfiled items moved to the right column. It did not make the prompt better than asking plainly. On the same notes, an ordinary "can you write this up as an update for the team please" scored 30 out of 30 against the rewritten starter's 29, and it had scored 29 the run before, on an identical prompt and identical notes. A one point movement with nothing changed is the same size as the difference the test set out to measure. Use the starter for the discipline of sorting, not because it is more accurate than asking plainly.
